# DegreePath AI

**Your Degree · Your Skills · Your Future**

نظام ذكي بيحلل المواد اللي الطالب درسها، يستخرج منها المهارات باستخدام NLP،
ويقارنها بمتطلبات الوظائف، ويحدد المهارات الناقصة (Skill Gap)، ويقترح
وظائف مناسبة وخطة تعلم (Learning Roadmap) بمصادر مجانية.

## التشغيل

المتطلبات: Python 3.10 أو أحدث. مفيش أي خدمات مدفوعة أو مفاتيح API.

```bash
cd degreepath
pip install -r requirements.txt
python app.py
```

افتح المتصفح على: http://localhost:5000

## تشغيل الاختبارات

```bash
python -m pytest tests/ -v
```

16 اختبار بيغطوا: التسجيل والدخول، الملف الشخصي، إضافة المواد، استخراج
المهارات (عربي وإنجليزي)، المطابقة، تحليل الفجوة، خطة التعلم، وعزل بيانات
كل مستخدم.

## رحلة الطالب في النظام

1. يسجل حساب جديد ويكمل ملفه الشخصي (جامعة، تخصص، سنة دراسية، وظيفة مستهدفة).
2. يضيف مواده: يدويًا (اسم + وصف) أو من قائمة مقررات القسم الجاهزة
   (قسم إدارة نظم المعلومات وتكنولوجياها - لائحة 2023/2024).
3. النظام يستخرج المهارات من وصف كل مادة تلقائيًا.
4. لوحة التحكم تعرض الوظائف مرتبة بنسبة التطابق مع مهاراته.
5. صفحة الوظيفة تعرض: نسبة التطابق، تحليل الفجوة (مهارات موجودة / ناقصة)،
   وخطة تعلم مرتبة بالأولوية بمصادر مجانية لكل مهارة ناقصة.

## الـ NLP في المشروع (أهم جزء علميًا)

خط المعالجة في `degreepath/nlp.py`:

1. **Normalization**: توحيد الأحرف (أ/إ/آ → ا، ة → ه، ى → ي)، إزالة التشكيل
   وعلامات الترقيم، مع الحفاظ على الرموز داخل المصطلحات (مثل `c++` و`node.js`).
2. **Tokenization** باستخدام تعبير نمطي يدعم الإنجليزي والعربي.
3. **Stopword removal** لكلمات الإيقاف الشائعة في وصف المواد.
4. **Skill extraction**: مطابقة نصية على حدود الكلمات (word boundaries) ضد
   قاموس مهارات فيه ~55 مهارة، كل مهارة ليها أسماء مستعارة بالإنجليزي والعربي
   (مثلاً: `power bi` و`باور بي أي` → Power BI). الأسماء الأطول تتطابق أولًا
   عشان "machine learning" ما تتقرأش "learning".

مثال من ملف المشروع:

```
Input:  "Students will learn Python programming, data manipulation,
         database management, and statistical analysis."
Output: Python, Data Analysis, Database Administration, Statistics
```

### ليه الطريقة دي؟

استخراج المهارات من قاموس (dictionary-based NER) مناسب هنا لأن: النطاق مغلق
ومعروف (مهارات سوق العمل التقنية)، النتائج قابلة للتفسير قدام الدكتور، ومفيش
حاجة مدفوعة أو موديلات خارجية. حدودها معروفة: مهارة مش في القاموس مش هتتكشف،
والقاموس قابل للتوسعة بسطر واحد في `skills_data.py`. لو المشروع اتوسع، الخطوة
الطبيعية الجاية هي نموذج تعلم آلة مُدرب على أوصاف مواد حقيقية.

## حساب نسبة التطابق

كل مهارة مطلوبة للوظيفة ليها وزن: أساسية (3)، مهمة (2)، ميزة إضافية (1).

```
match % = مجموع أوزان المهارات المتوفرة عند الطالب / مجموع أوزان كل المهارات المطلوبة × 100
```

الوظائف تترتب تنازليًا بالنسبة. خطة التعلم ترتب المهارات الناقصة بالأهمية ثم
بعدد الوظائف الأخرى اللي بتحتاجها (الأكثر فايدة أولًا)، وكل مهارة مربوطة
بمصادر تعلم مجانية (Kaggle، freeCodeCamp، Microsoft Learn، ...).

## ملاحظات معروفة

- أسماء مقررات القسم اتنقلت من صورة موبايل للائحة 2023/2024، يُفضل مراجعتها
  على اللائحة الرسمية قبل العرض.

## النموذج المدرّب (Trained ML Model)

بالإضافة لمستخرج القاموس، المشروع فيه نموذج تعلم آلة مدرّب فعليًا، بيشتغل أوفلاين بالكامل ومفيهوش أي خدمات مدفوعة أو API:

- **المعمارية:** OneVsRest LogisticRegression فوق TF-IDF (كلمات 1-2 + حروف 3-5) — تصنيف متعدد العلامات (multi-label) على 61 مهارة.
- **بيانات التدريب:** 3884 عيّنة من داخل المشروع: جمل مولّدة من قاموس المهارات (بالإنجليزي والعربي) + وصف المواد والوظائف الموجود في قاعدة البيانات.
- **التكامل:** `nlp.extract_skills_hybrid` بيجمع القاموس والنموذج، وكل مهارة متعلّمة بمصدرها (`dictionary` / `model` / `both`) مع درجة الثقة.

### المقاييس المقاسة (test set محجوز 20%)

| المقياس | micro | macro |
|---|---|---|
| Precision | 0.987 | 0.989 |
| Recall | 0.779 | 0.775 |
| F1 | 0.871 | 0.859 |

> بصراحة: البيانات مولّدة من نفس القاموس، فالمقاييس دي بتقيس تعميم النموذج على صياغات جديدة لنفس المهارات، مش على مجال جديد تمامًا. الـ recall الأقل من الـ precision معناه إن النموذج متحفظ: لما بيتنبأ بيكون غالبًا صح.
